
# Modern Dark Developer Portfolio

A dark, editorial-style developer portfolio built with Vite, React, and Tailwind CSS. It highlights Kajol Gehlot's profile, experience, featured projects, technical skills, and contact details in a modern single-page layout.

## Features

- Full-screen hero section with bold typography and a looping marquee
- Modern About section with a timeline and visual highlight cards
- Featured projects pulled from the resume and presented in a clean list layout
- Skills, contact, and footer sections with consistent styling
- Responsive design tuned for desktop and mobile screens

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React icons

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

- `src/main.tsx` - Application entry point
- `src/app/App.tsx` - Main portfolio layout and content
- `src/styles/` - Global styling, theme tokens, and custom utilities
- `src/imports/` - Static assets used by the portfolio

## Notes

The portfolio content is intentionally data-driven inside `src/app/App.tsx` so it is easy to update projects, skills, and contact information in one place.
